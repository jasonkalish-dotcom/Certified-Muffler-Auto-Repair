# Certified Muffler and Auto Repair

Website for Certified Muffler and Auto Repair, Inc. — 9 Mill St, Port Chester, NY 10573 · (914) 939-4632.

## View the site

Double-click **`index.html`** to open it in your web browser (Chrome, Edge, Safari or Firefox).
Keep the `images/` folder next to it. No server or install needed.

If you only see the shop's name and phone number, the file was opened somewhere that
doesn't run JavaScript (for example a zip or file previewer). Extract the zip first, then
open `index.html` in a browser.

## Develop

Built with React, TypeScript, Vite, Tailwind CSS, Framer Motion and Lucide React.

```bash
npm install
npm run dev      # dev server (opens dev.html)
npm run build    # rebuild index.html after making changes
```

- `dev.html` is the editable page template; `index.html` is generated by `npm run build`.
- Business details (phone, address, rating, links) live in `src/data.ts`.
- Shop photos live in `images/`. Replace them with higher-resolution originals using the
  same filenames for sharper results.
